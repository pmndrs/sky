title: Sky

`Sky` (`import { Sky } from '@pmndrs/sky'`) is the high-level wrapper around
[`SkyAtmosphereBaker`](./baker). It targets the 90% case: pick a preset, set
time-of-day + latitude, `attach()` to a scene, call `update(camera)` per
frame. Power users can reach `sky.baker` directly for the lower-level
surface, or use [`applyHaze`](../guides/haze) for custom post-process
chains.

This page documents the public surface as implemented in `src/Sky.ts`.

## Constructor

```js
new Sky(renderer, options?)
```

`renderer` is a `THREE.WebGPURenderer` that has already resolved
`await renderer.init()`.

| Option                    | Default     | Notes                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `preset`                  | `'earth'`   | `'earth' \| 'mars' \| 'titan'` — see [`presets`](../guides/tuning-atmosphere)                                                                                                                                                                                                                                                                         |
| `quality`                 | `'medium'`  | `'low' \| 'medium' \| 'high'` — LUT resolution tier (sizes in [LUTs](./luts)). Unknown values silently fall back to `'medium'`.                                                                                                                                                                                                                       |
| `cubeSize`                | `256`       | Cube-render-target face size (px) used for the background/IBL bake.                                                                                                                                                                                                                                                                                   |
| `atmosphere`              | —           | Partial `AtmosphereParams`, merged onto the resolved preset. See [Tuning the atmosphere](../guides/tuning-atmosphere).                                                                                                                                                                                                                                |
| `exposure`                | `40`        | Initial `luminanceScale` (see [LUTs](./luts) — the `ILLUMINANCE_IS_ONE` contract).                                                                                                                                                                                                                                                                    |
| `north`                   | `'+Z'`      | `'+X' \| '-X' \| '+Z' \| '-Z'`, or a heading in degrees clockwise from +Z seen from above (`90` = `'-X'`). Where geographic north points; see [Compass](#compass).                                                                                                                                                                                    |
| `sunDisc`                 | `true`      | `boolean` or `{ visible?, angularDiameter?, edgeSoftness? }` — see `setSunDisc`.                                                                                                                                                                                                                                                                      |
| `sunColor`                | `'neutral'` | Colour of the sun as a light source — see `setSunColor`.                                                                                                                                                                                                                                                                                              |
| `timeOfDay`               | `12`        | Hours, `0..24`. Combined with `latitude` + `dayOfYear` via NOAA solar position.                                                                                                                                                                                                                                                                       |
| `latitude`                | `37.7`      | Degrees.                                                                                                                                                                                                                                                                                                                                              |
| `dayOfYear`               | `172`       | `1..365`.                                                                                                                                                                                                                                                                                                                                             |
| `sunDirection`            | —           | `{ elevation, azimuth, raw? }` degrees — bypasses solar-position math entirely if provided. `azimuth` is a compass azimuth (clockwise from north); see `setSunDirection`.                                                                                                                                                                             |
| `turbidity`               | `1`         | Top-level shortcut scalar; multiplies Mie scattering/extinction/absorption on the resolved preset before construction.                                                                                                                                                                                                                                |
| `groundAlbedo`            | —           | Top-level shortcut; number or `Vector3`/`{x,y,z}`. Unset, the preset's value applies (Earth: `0.1`).                                                                                                                                                                                                                                                  |
| `enableAerialPerspective` | `true`      | Builds the aerial-perspective LUT + compute pipeline. Set `false` to skip it entirely (cheaper; `applyHaze` throws if you didn't enable it; `applyFog` works without).                                                                                                                                                                                |
| `apKmPerSlice`            | `8.0`       | Aerial-perspective LUT depth-slice size in km. Bump for planet-scale views — see [Planet-scale guide](../guides/planet-scale).                                                                                                                                                                                                                        |
| `mirrorBelowHorizon`      | `false`     | Y-mirrors the cube bake's lower hemisphere instead of lit-ground-albedo content — useful for reflective-floor scenes. See `setMirrorBelowHorizon`.                                                                                                                                                                                                    |
| `pmrem`                   | `{}`        | `SkyPmremOptions`. `generator: 'sky'` (default) re-filters the IBL on every sky change with WebGPU compute (~1 ms; `quality: 'three' \| 'fast'`); `'three'` uses three's `PMREMGenerator`, throttled by `minInterval` / `levelsPerFrame` (also the WebGL-backend fallback). See [Environment (PMREM) refresh](<./baker#environment-(pmrem)-refresh>). |

## Getters

| Getter                                | Returns                                                                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `sky.texture`                         | Raw baked cube texture (`baker.texture`) — what `scene.background` is set to.                                            |
| `sky.environmentTexture`              | PMREM-filtered cube (`baker.environmentTexture`) — what `scene.environment` is set to.                                   |
| `sky.aerialPerspectiveTexture`        | The 3D aerial-perspective LUT texture, or `null` if `enableAerialPerspective: false`.                                    |
| `sky.mesh`                            | The baker's internal `SkyAtmosphereMesh` (lives in the baker's private scene, **not** your main scene — see note below). |
| `sky.sunElevation` / `sky.sunAzimuth` | Current sun direction in degrees, as last set via `setTimeOfDay`/`setSunDirection`/etc.                                  |
| `sky.north`                           | Heading of geographic north in degrees, clockwise from +Z seen from above (see [Compass](#compass)).                     |
| `sky.stars`                           | The `SkyNight` instance if `enableStars()` was called, else `null`. See [Night sky](../guides/night-sky).                |
| `sky.state`                           | `'detached'`, `'attached'` or `'disposed'`. Accessing `sky.baker` after disposal throws.                                 |

> **Note:**
> `sky.mesh` is the mesh the baker renders into its private cube camera — it
> is not attached to your scene and won't appear unless you add it yourself.
> If you want a _live_ sky mesh in your own scene (one that updates every
> frame instead of only on cube re-bake, useful at planet scale where
> altitude changes fast), use `sky.baker.createSkyMesh({ scale, showSunDisc })`
> instead — see `examples/vanilla/component-03-planet.html` for a working
> example. That mesh gets `renderOrder = SKY_RENDER_ORDER`: it draws after
> your opaque geometry, depth-tested at the far plane without writing depth,
> so sky pixels hidden behind geometry are rejected before shading
> (transparent objects still draw over it). Give a `SkyAtmosphereMesh` you add
> yourself the same `renderOrder` (`import { SKY_RENDER_ORDER } from '@pmndrs/sky'`).

## Lifecycle

| Method                      | Description                                                                                                                                        |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `attach(scene, options?)`   | Sets `scene.background` and/or `scene.environment` (both by default) and adds the star sprites. See [Attach roles](#attach-roles). Returns `this`. |
| `detach()`                  | Clears the slots it set (only if they still point at this sky's textures) and removes the stars. Returns `this`.                                   |
| `compileAsync()`            | Compiles the sky's internal shaders without blocking. Await once before the first `update()`. See [Shader compilation](#shader-compilation).       |
| `update(camera, opts?)`     | Per-frame entry point — see below.                                                                                                                 |
| `updateAerialPerspective()` | Runs the AP LUT compute pass. Call every frame if you've wired `applyHaze`.                                                                        |
| `flushEnvironment()`        | Finishes any throttled / time-sliced IBL refresh now, so `environmentTexture` matches the current sky (screenshots, hard cuts). Returns `this`.    |
| `dispose()`                 | Detaches, removes the stars and frees the Milky Way map, and disposes the baker. Idempotent; baker-backed calls then throw.                        |

> **Warning:**
> `dispose()` does not dispose helpers created by `createSun`, `createGround`, `createGroundedSkybox`, or `createMoon`.
> Call `dispose()` on sun, ground, and moon helpers. For a grounded skybox, dispose its `geometry` and `material`.

### Attach roles

```js
sky.attach(scene, { background: true, environment: false })
```

| Option        | Default | Slot                                                                     |
| ------------- | ------- | ------------------------------------------------------------------------ |
| `background`  | `true`  | `scene.background` ← `sky.texture` (the raw cube).                       |
| `environment` | `true`  | `scene.environment` ← `sky.environmentTexture` (the PMREM-filtered IBL). |

Turn a role off to keep that slot your own: `{ environment: false }` shows the
procedural sky outside while an indoor HDRI lights the scene, and
`{ background: false }` lights with the sky behind your own backdrop. The
sky never writes a slot it did not claim, and the star sprites from
`enableStars()` join the attached scene whatever the roles.

Calling `attach()` again on the same scene with different roles releases a
slot no longer requested and claims a newly requested one (claiming
overwrites what is there). `detach()`, `dispose()` and attaching to another
scene clear only claimed slots that still hold this sky's textures.

### Shader compilation

```js
await renderer.init()
const sky = new Sky(renderer, { timeOfDay: 16 })
sky.attach(scene)
await Promise.all([sky.compileAsync(), renderer.compileAsync(scene, camera)])
renderer.setAnimationLoop(frame)
```

The first `update()` needs a handful of shaders: the three lookup-table passes,
the background cube capture and, with haze, the aerial-perspective pass. three
compiles a shader it first meets during a draw synchronously. Chrome compiles
WebGPU shaders in its GPU process, so a synchronous compile stalls it until
the shader is ready, right as the first frame is being prepared. On Windows,
where each shader goes through WGSL → HLSL → DXC (or FXC on older drivers),
that can hold up the first frame by a second or more; on macOS it is much
shorter. `compileAsync()` compiles them in the background instead.

It is optional: skip it and the first `update()` compiles synchronously, as
before. It covers the sky's own off-screen passes, which your
`renderer.compileAsync(scene, camera)` never reaches, and the IBL prefilter,
whose texture stays black until its pipelines are ready. On WebGPU nothing
in the sky's bake then compiles synchronously. The
React `<Sky>` calls it for you and holds the first bake until it settles.

### `update(camera, opts?)`

```js
sky.update(camera, { planetCenter? })
```

Call once per frame with the active render camera. Internally:

1. `baker.setCamera(camera, opts)` — feeds camera height/position into the
   Sky-View LUT and (if wired) the aerial-perspective LUT's camera uniforms.
2. Syncs the looks' display scale to `1 / renderer.toneMappingExposure`
   (`1` under `NoToneMapping`) so a [look](../guides/looks) keeps its authored
   colours when exposure changes; a change re-bakes the cube.
3. `baker.update()` — re-runs only the dirty LUT stages (see
   [Baker: dirty-flag semantics](./baker#dirty-flag-semantics)).
4. Fills `scene.environment` once the first PMREM bake exists, if
   `attach()` claimed it: the IBL is `null` before that bake. It only writes
   a slot that is empty or still holds what the sky wrote, so a texture you
   assign later stays put.
5. If `enableStars()` was called, moves the star sprites with the camera.

Pass `{ planetCenter: someVector3 }` for spherical-planet scenes so
altitude is computed as distance-from-center instead of world `y`. See the
[Planet-scale guide](../guides/planet-scale).

`updateAerialPerspective()` is **not** called automatically by `update()` —
it must fire every frame regardless of dirty flags (camera moves every
frame), so it's a separate call. Only needed if you've wired `applyHaze`.

## Sun and time

| Method                                          | Notes                                                                                                                                                                                                 |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `setTimeOfDay(hours)`                           | Recomputes sun direction via NOAA solar position using the current `latitude`/`dayOfYear`.                                                                                                            |
| `setLatitude(deg)` / `setDayOfYear(day)`        | Same — recompute sun direction.                                                                                                                                                                       |
| `setSunDirection({ elevation, azimuth, raw? })` | Direct override, bypasses solar-position math. `azimuth` is a compass azimuth, degrees clockwise from `north` (90 = east), unless `raw: true` (feeds the baker's raw spherical-coord theta directly). |
| `setNorth(north)`                               | An axis or a heading in degrees. Turns the sun, stars, Milky Way and a manual `SkyMoon` together; `sky.north` reads the heading back.                                                                 |

### Compass

Azimuths are compass azimuths: degrees clockwise from north, 90 = east, as
on a map. `north` says where geographic north points in your world: one of
the axes, or a heading in degrees, turning clockwise seen from above (looking
down −Y), starting at +Z.

| `north` | Heading | East is |
| ------- | ------- | ------- |
| `'+Z'`  | `0`     | −X      |
| `'-X'`  | `90`    | −Z      |
| `'-Z'`  | `180`   | +X      |
| `'+X'`  | `270`   | +Z      |

Facing north, east is on your right. Set the heading once, for example to
match a site plan, and keep driving the sky with `setTimeOfDay`,
`setLatitude` and `setDayOfYear`: the sun, the stars, the Milky Way and a
`SkyMoon` placed with `setDirection` all turn with it.

```js
sky.setNorth(-23.5) // the plan's north arrow is 23.5° counter-clockwise of +Z
sky.setTimeOfDay(16) // afternoon sun, already in the plan's frame
```

## Haze

before `applyHaze` too: it adopts their values, and only an option passed to
`applyHaze` explicitly overrides them (the same holds for `setFog` and
`applyFog`). Facade methods:

| Method                                        | Notes                                                                                                                                                                                                                                                                                           |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `applyHaze(sceneColorNode, options)`          | Returns a `vec4` TSL output node. Throws if `enableAerialPerspective` was `false`.                                                                                                                                                                                                              |
| `setHazeStrength(n)`                          | Multiplies inscatter colour + AP alpha (`1` = physical, `0` = no haze).                                                                                                                                                                                                                         |
| `setHazePolicy('auto' \| 'ap' \| 'raymarch')` | Switch policy live.                                                                                                                                                                                                                                                                             |
| `setHazeAltitudeBlend({ startKm?, endKm? })`  | Adjust the `'auto'`-mode altitude blend window.                                                                                                                                                                                                                                                 |
| `setHazeShadows(opts)`                        | Live knobs for [light shafts](<../guides/haze#light-shafts-(shadowed-haze)>): `{ light, samples, maxDistance, strength, resolution }`; omitted fields are left as is. The shadow march is compiled in only when `applyHaze` gets `shadows`, or when this supplied a `light` before `applyHaze`. |
| `applyFog(sceneColorNode, options)`           | [Height fog](../guides/haze#height-fog:-the-budget-tier), the budget tier: a `vec4` node fading geometry into the sky along its ray. No per-frame LUT; works with `enableAerialPerspective: false`. Options: `scenePass`, the `setFog` knobs, `nightBlur`, `debugMode`.                         |
| `setFog(opts)`                                | Live height-fog knobs `{ density, heightFalloff, baseHeight, maxOpacity }` (per km, m, m, `0..1`); omitted fields are left as is. Works before or after `applyFog`.                                                                                                                             |

## Helper factories

Each factory returns a standalone helper bound to this `Sky` — call
`.attach(scene)` (or add the returned mesh directly) yourself.

| Method                                    | Returns                                                                                                                 |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `createSun(opts?)`                        | `SkySun` — owns a `DirectionalLight` that auto-tracks every sun-direction change.                                       |
| `createGround(opts?)`                     | `SkyGround` — a ground plane/sphere auto-sized from `bottomRadius`.                                                     |
| `createGroundedSkybox(opts?)`             | `GroundedSkybox` mesh — reprojects the cube's lower hemisphere onto a flat disc.                                        |
| `createMoon(opts?)`                       | `SkyMoon` — owns a moonlight `DirectionalLight`; tracks anti-sun + phase by default.                                    |
| `enableStars(opts?)` (async)              | Creates/updates the night sky (star sprites + Milky Way); returns the `SkyNight`. See [Night sky](../guides/night-sky). |
| `disableStars()` / `setStarsIntensity(v)` | Hide the night sky / scale the stars once created (see `sky.stars`).                                                    |

For debugging the sun's direction, `new SkyHelper(sky, { size })` (exported
from `@pmndrs/sky`) is an `Object3D` showing a compass ring, the sun arrow and
its elevation arc. Its red tick marks +Z, which is north only for the default
`north: '+Z'`; the ring does not turn with `setNorth`. Add it to your scene and
call `helper.dispose()` when done.

### `SkySun`

```js
const sun = sky.createSun({ intensity: 4, castShadow: true }).attach(scene)
sun.fitShadowToObject(scene)
```

| Option          | Default            | Notes                                                                                                                                 |
| --------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| `intensity`     | `4` (physical `1`) | Requested daytime intensity. With `physical: true`, a multiplier on the sky-derived illuminance.                                      |
| `horizonFade`   | `true`             | Fade the light with the fraction of the sun's disc above the horizon. `false` keeps it on below the horizon (cinematic lighting).     |
| `physical`      | `false`            | Derive intensity and tint from the sky: `intensity × exposure × T(sun)`. See below.                                                   |
| `color`         | `0xffffff`         | Base colour, multiplied by the sky's [sun colour](../guides/tuning-atmosphere#sun-colour).                                            |
| `distance`      | `50000`            | Light distance along the sun ray (metres), for the shadow camera.                                                                     |
| `target`        | new `Object3D`     | The light's target.                                                                                                                   |
| `castShadow`, … | `true`, …          | `shadowMapSize` (2048), `shadowBias`, `shadowNormalBias`, `shadowRadius`, `shadowCamera` (`{ left, right, top, bottom, near, far }`). |

`sun.intensity` is the **requested** intensity and `sun.light.intensity` the
**effective** one. The light is re-synced on every sun change
(`setTimeOfDay`, `setSunDirection`, latitude, date, north), sun-colour change
and intensity edit, so set intensity and colour through `sun.intensity` /
`setIntensity(v)` and `setColor(c)`: a value written straight to
`sun.light.intensity` or `sun.light.color` is overwritten by the next sync.
Other setters: `setHorizonFade(bool)`, `setPhysical(bool)` (also the
`horizonFade` / `physical` properties), `setDistance`, `fitShadowToBox`,
`fitShadowToObject`, `attach`, `detach`, `dispose`.

**Horizon fade.** The light scales with the visible fraction of the sun's
disc: full while the whole disc is up, half with its centre on the horizon,
off once it has set. The band is one disc diameter (~0.53°, or whatever
`setSunDisc({ angularDiameter })` set), so the light goes out when the
visible sun does. The horizon is the flat world's (elevation 0 against world
+Y), like `SkyMoon`'s; it does not follow the camera around a planet in
planet mode.

**Physical mode.** `createSun({ physical: true })` sets the light to
`intensity × luminanceScale × T(sun)`: the sky's exposure times the
transmittance from the top of the atmosphere to the camera's altitude along
the sun direction, tinted by `T` and the sun colour. The LUTs hold sky
radiance for a sun of illuminance 1 at the top of the atmosphere, so in the
sky's units the sunlight's illuminance is exactly that, with no extra
constant. `T` comes from a CPU twin of the Transmittance LUT (it matches the
GPU LUT to half-float precision), so the light dims and reddens toward the
horizon like the sun disc, and goes dark when the planet hides the sun. At
the defaults (exposure 40, noon in late June at 37.7° N) the light's
luminance is ~35.5, about 9× the default constant `4`: a white Lambertian
surface in full sun reads ~11, 13–16× the open sky, as in daylight. Lower
`toneMappingExposure` accordingly when switching an existing scene over.

It follows the sun immediately, and `setExposure`, atmosphere changes and the
camera's altitude on the next `sky.update()` (through
[`baker.addBakeListener`](<./baker#addbakelistener(fn)>); nothing runs on frames
where the sky did not change). With `horizonFade` on, the flat-world horizon
decides when the disc has set; with it off, the planet's true horizon from
the camera's altitude does. The transmittance already dims a low sun, so
there is no second ramp.

### `SkyMoon`

```js
const moon = sky.createMoon({ intensity: 0.15, phase: 0.5 }).attach(scene)
moon.setPhase(0.75) // last quarter
moon.setDirection({ elevation: 30, azimuth: 120 }) // or place it by hand
```

A moonlight `DirectionalLight` plus a moon disc drawn on the sky. It is a
scene light only: it does not light the atmosphere. By default
(`followSun: true`) it is placed from the sun and the lunar `phase` (0 = new
moon at the sun, 0.5 = full moon opposite it). `setDirection({ elevation,
azimuth })` places it by hand with a compass azimuth, clockwise from the
sky's `north`, like `setSunDirection`; it turns with `setNorth` and stops
following the sun until `setFollowSun(true)`. The light fades out between 0°
and −2° of moon elevation, keeping the requested `intensity`.

Options: `intensity` (`0.15`), `color` (`0xb0c8e0`), `phase` (`0.5`),
`followSun` (`true`), `showDisc` (`true`), `discIntensity`,
`discAngularDiameter` (radians, ≈0.00935), `discColor`, `distance`,
`target`, and the shadow options of `SkySun` (`castShadow` defaults to
`false`). Setters: `setIntensity`, `setPhase`, `setDirection`,
`setFollowSun`, `setDistance`, `setDiscVisible`, `setDiscIntensity`,
`setDiscAngularDiameter`, `setDiscColor`, `fitShadowToBox`,
`fitShadowToObject`, `attach`, `detach`, `dispose`.

## `presets`

`import { presets } from '@pmndrs/sky'` re-exports the same
`Record<string, AtmosphereParams>` used internally by `preset` / `setPreset`
— useful for building a preset picker. See
[Tuning the atmosphere](../guides/tuning-atmosphere).
