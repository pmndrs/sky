This page is the workflow: open the editor, author a grade across the day,
save it, and load it in an app. For what a grade _is_ and every field it
takes, see [Sky grades](./sky-grades).

## Run it

```sh
pnpm install
pnpm --filter @pmndrs/sky-example-vanilla dev
```

Then open `http://localhost:5173/25-sky-grade-editor.html`. The editor needs a
browser with WebGPU (current Chrome, Edge or Safari).

## The layout

The demo scene fills the page, and the packaged Sky Editor floats over it. Drag
its title bar to move it, resize it from the corner, or close it and reopen with
**Sky Editor**. The camera's **Sun / Away / Up / Ground** buttons remain outside
the tool.

| Area                   | What it does                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Toolbar                | Grade name, undo/redo, Physical comparison, Load, Save grade and Copy JSON                                                     |
| Solar controls         | Follow the app's sun, scrub time or manual elevation, and play the day                                                         |
| Timeline               | Sun elevation, twilight marks, zenith/sun-side/away swatches, keyframes and playhead                                           |
| Grade tab              | Flattened dome preview with guides and zone picking, next to the keyframe inspector                                            |
| Sun and Atmosphere tab | Physical environment controls: planet preset, exposure, turbidity, albedo, sun appearance and advanced atmosphere coefficients |

The dome has four modes: **Split**, **Graded**, **Physical**, and **Grade
only** (the grade applied to flat grey). **Zone guides** show the horizon/zenith
boundary, directional zone widths and sun glow. The **Physical** toolbar toggle
bypasses the grade throughout the scene and temporarily switches the dome to
Physical. Grade export still uses the authored grade.

## Authoring a grade

1. **Pick a starting point** from **Preset**: a built-in grade
   (`storybook`, `blue-night`), a fixed gradient, a tinted gradient that keeps
   the physical light, a solid colour, or **Physical** (no keyframes).
2. **Scrub to a time that looks wrong.** Drag on the timeline, or use the
   time slider, ← / → (⇧ for bigger steps), or play the day with Space.
3. **Edit.** On a keyframe, the panel edits it. Between keyframes it shows
   what the grade does there, and your first edit adds a keyframe at the
   playhead. A grade with a single keyframe holds all day, so the editor edits
   that keyframe wherever the playhead is — press `K` to add a second one and
   make the sky follow the time of day.
4. **Find the zone you need** by clicking the sky in the dome view: the
   inspector scrolls to that zone and flashes it.
5. **Compare** with `B` (or the **Physical** button) to flip to the physical
   sky and back.
6. **Check the night.** Scrub below −6°: the **night fill** keeps the sky
   blue instead of black, and **ambient light** keyed on the same keyframes
   lights the scene.

Keyframes: click one to jump to it, drag it to move it (⇧ snaps to whole
degrees), double-click empty timeline to add one, ⌫ to delete the selected
one. Double-click a slider to reset it. Undo / redo is ⌘Z / ⇧⌘Z (Ctrl on
Windows and Linux), and the demo saves a browser draft. Restore a saved draft explicitly with
**Restore draft**. Shortcuts act while the editor is focused and preserve text
editing.

## Getting a grade into your app

**Save grade** downloads `<name>.json`; **Copy JSON** puts the same text on the
clipboard. It is the whole interface — any bundler imports JSON:

```js
import { Sky, registerGrade } from '@pmndrs/sky'
import dusk from './dusk.json'

const sky = new Sky(renderer, { timeOfDay: 19 })
const grade = sky.setGrade(dusk) // an editable SkyGrade
grade.updateKey(0, { exposure: 0.2 }) // tweak at runtime

registerGrade('dusk', dusk) // or by name: sky.setGrade('dusk')
```

`sky.setGrade` also takes the JSON as a string (from `fetch`, `localStorage`,
a CMS field). In React:

```jsx
<Sky grade={dusk} />
```

For the night light, add `sky.createAmbient().attach(scene)`: it follows the
grade's ambient keyframes when the grade has them. To keep dusk and night
gradients from banding at 8 bits, end your post-processing with
[`ditherOutput`](./sky-grades#banding-dither-the-output).

The file is versioned (`format: 'pmndrs-sky-grade'`, `version: 1`) and stores
colours as sRGB hex, so it diffs and reviews well in a repo.

## The editor in your own app

Import the same tool the demo uses:

```js
import { createSkyEditor } from '@pmndrs/sky/editor'

const editor = createSkyEditor({ sky, renderer, open: false })
editSkyButton.addEventListener('click', () => editor.toggle())
// Existing loop: editor.update(dt) before sky.update(camera),
// then editor.render() after your scene render.
```

See [Embedded Sky Editor](./sky-editor) for clock coordination, physical
settings, callbacks, input isolation, cleanup and rendering on demand. Grade
files contain color authoring; physical atmosphere settings are saved separately
by the host app.

For custom authoring UI, the underlying public primitives remain available:
`SkyGrade` for edits and serialization, `SkyGradePreview` for the dome, and
`grade.apply` / `gradeZoneWeights` for CPU swatches and zone picking. The packaged
panels live in `src/editor` and reuse these APIs.

## Demos and scripts

`26-floating-sky-editor.html` shows a smaller app with an independent day/night
clock. `scripts/verify-sky-editor.mjs` checks authoring, physical controls,
comparison, renderer state and disposal in a real WebGPU browser.

| Page / script               | What it shows                                                                                                                                         |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `25-sky-grade-editor.html`  | The packaged editor over a scene with haze, ambient light and stars.                                                                                  |
| `component-01-baked.html`   | The drop-in baked sky with a **Grade** panel: physical, the built-in grades, or `horizonToZenith` with two colour pickers and a `replace` slider.     |
| `component-06-ghibli.html`  | A stylized countryside on a five-keyframe gradient grade (`ghibli-summer`), with amount / replace overrides and horizon-band controls.                |
| `14-night-sky.html`         | Stars and the Milky Way through twilight — pair with `blue-night` or `createAmbient()` for a lit night.                                               |
| `scripts/verify-grade.mjs`  | Headless check that the GPU grade matches `SkyGrade.apply` at a keyframe and between two (worst error a few 8-bit levels). Run with `BASE=<dev url>`. |
| `scripts/probe-shaders.mjs` | Shader sizes and sync/async compiles per page, for keeping an eye on what the grade adds.                                                             |
